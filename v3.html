Help / About — Home Designer v3

Architecture (brief): One shared versioned JSON model (project, version 3) holds plot, floors, walls, rooms, openings, stairs, furniture, sketches and dimensions in feet. The 2D canvas and the Three.js 3D scene are both rendered from that same model, so an edit in either view updates the other. Projects autosave to localStorage and can be downloaded / reopened as .json files.

What was implemented

  • Empty start; plot in ft/in; floors (Basement / Ground / First / Second / Rooftop) with elevation, slab thickness, wall height, duplicate / hide / delete.
  • 2D tools: Select, Wall, Room, Door, Window, Vent/Gate, Stairs, Furniture, Pencil sketch, Eraser, Dimension, Label — with snap (6 in), grid (1 ft), undo/redo, copy/paste, duplicate.
  • Stairs with from/to floors, steps, tread, riser auto-calc, type (Straight / L / U / Spiral-simplified), direction, landings, and a slab opening on the arrival floor. Staircase test-case template included.
  • 3D: OrbitControls, perspective/orthographic, camera presets incl. rear-entrance eye height 5'6", hide walls/roof/ceilings, cutaway, show-only-current-floor, real wall openings (lintels), stepped stairs, furniture in matching positions.
  • Export: clean 2D-plan and 3D-view PNGs with optional dimensions/labels and resolution choices. Save: autosave + .json download/open.

Honest limitations

  • Spiral stairs are simplified (curved steps, not a true helical stringer).
  • No curved-wall 3D — curved lines stay as 2D sketches/guides.
  • No plumbing, electrical, or services modelling.
  • No building-code compliance check — warnings are geometry only (headroom, reach, overlap).
  • 3D editing is select + Properties only (no 3D dragging).
  • Small-screen editing is cramped; desktop-first.
  • Video / walkthrough export is out of scope.
